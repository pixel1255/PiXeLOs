# flake.lock

Lockdatei der NixOS-Flake.

Sie fixiert die exakte Version der verwendeten Flake-Inputs und
macht Builds reproduzierbar.

Aktueller nixpkgs-Pin der Version-0-Basis:

- Branch: `nixos-unstable`
- Revision: `e5bdc4a41d4c072fe1e3787eaa0320a384741d44`
- Kurzrevision: `e5bdc4a`

Die Lockdatei sollte normalerweise nicht von Hand editiert werden.

Eine bewusste Aktualisierung erfolgt spaeter beispielsweise mit:

    nix flake update

Danach wird zuerst gebaut und getestet, bevor eine neue stabile
Version entsteht.

`flake.lock` gehoert deshalb zusammen mit `flake.nix` ins Git.
