# hardware-configuration.nix

Hardware- und Datentraeger-spezifische Konfiguration des Intel-Hosts.

Enthaelt insbesondere:

- benoetigte Initrd-Kernelmodule
- SATA / USB Storage Basismodule
- Root-Dateisystem
- EFI-Boot-Dateisystem
- feste UUIDs der Intel-SSD
- Swap-Konfiguration
- Host-Plattform `x86_64-linux`

Aktueller Intel-Datentraeger:

Root:
- Label: `NIXOS_ROOT`
- UUID: `2812c87f-9d4f-4b4f-a554-579a4ae40d13`

EFI:
- Label: `NIXOS_EFI`
- UUID: `28A0-0C37`

Diese Datei ist an die physische Hardware gebunden.

Bei einem Wechsel der Systemplatte oder grundlegender Hardware
muss diese Datei besonders sorgfaeltig geprueft werden.
