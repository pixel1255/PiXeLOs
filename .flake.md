# flake.nix

Einstiegspunkt der NixOS-Flake.

Aufgabe:

- definiert `nixpkgs` als Input
- definiert die Zielplattform `x86_64-linux`
- erzeugt die NixOS-Konfiguration `pixel1255`
- bindet `configuration.nix` als Hauptkonfiguration ein

Das System wird ueber dieses Ziel gebaut:

    .#pixel1255

Typischer Test:

    sudo nixos-rebuild test --flake .#pixel1255

Nach erfolgreichem Test:

    sudo nixos-rebuild switch --flake .#pixel1255

Die eigentlichen Host-Einstellungen liegen nicht hier,
sondern in `configuration.nix`.
